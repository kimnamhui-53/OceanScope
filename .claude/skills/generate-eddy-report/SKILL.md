# 동해 소용돌이 분석보고서 생성 (오션스코프 보고서 모듈)

인자로 대상 연도를 받는다 (예: `2026`, `2024`). 인자가 없으면 사용자에게 연도를 물어본다.

## 절차

### 1단계: 파이프라인 실행

```
python code/run_pipeline.py <연도>
```

> 모든 스크립트는 `code/` 폴더에 있고, 경로는 `code/paths.py`가 결정한다.
> 프로젝트 루트에서 위와 같이 실행하면 된다.

- 월별(1~12월, 각 15일자)로 CMEMS 데이터 다운로드 → 그래프 3종 + 통계 JSON 생성
- 오래 걸리므로(월당 수 분) 백그라운드 실행 후 완료를 기다릴 것
- 일부 월이 실패해도 중단하지 말고, 완료된 월만으로 진행 후 실패 월을 사용자에게 보고
- `copernicusmarine` 미설치 또는 미로그인 오류 시: `pip install copernicusmarine` 후 사용자에게 `copernicusmarine login` 실행을 요청

산출물 (자료별 폴더 × figure/json, 날짜는 `YYYYMM15`):
- `output/eddy_tracking/figure/WA_Method_<날짜>.png` — 소용돌이 분포
- `output/eddy_tracking/json/eddy_stats_<날짜>.json` — 소용돌이 개수 (warm, cold, ulleung_warm, dokdo_cold)
- `output/eastsea_current/figure/eastsea_current_<날짜>.png` — 준실시간 해류도
- `output/eastsea_sst/figure/eastsea_temp_<날짜>.png` — 위성 표층 수온
- `output/eastsea_sst/json/sst_stats_<날짜>.json` — 수온 통계 (동해 전역/울릉도·독도 min·max·mean, 수온전선 위도)
- `output/intermediate/summary/summary_<연도>.json` — 위 통계 취합본

### 2단계: 월별 코멘트 작성

각 월에 대해 **그래프 PNG 3장을 Read 도구로 직접 보고**, `eddy_stats`/`sst_stats` JSON을 읽은 뒤 코멘트를 작성한다.

**첫 문장은 반드시 고정 템플릿** (eddy_stats JSON의 값을 그대로 대입, 절대 다른 수치 사용 금지):

> 동해에 나타난 소용돌이는 난수성 {warm}개, 냉수성 {cold}개이며, 울릉도‧독도 주변해역에 나타난 소용돌이는 난수성 {ulleung_warm}개, 냉수성 {dokdo_cold}개이다.

**이후 서술 (2~3문장)**은 그래프에서 실제로 보이는 것과 sst_stats 수치에 근거해 작성:
- 수온전선: 위치(북위 N°)와 그 부근 수온 (sst_stats의 front.lat, front.sst_at_front 참고, 그래프로 검증)
- 울릉도‧독도 해역 수온 분포 (ulleung_dokdo.mean 참고, "약 X~Y℃ 분포")
- 소용돌이 발달 양상: 어느 해역에서 난수성/냉수성이 발달·약화했는지 (WA_Method 그래프 판독)
- 해류: 동한난류·대마난류의 강약 (eastsea_current 그래프 판독)
- 전월 대비 변화를 반드시 1개 이상 언급 (1월은 제외 가능)

**문체 예시 (2025 보고서 원문 — 이 톤과 어휘를 따를 것):**

> (2월) …울릉도‧독도 주변해역에서 난수성 소용돌이가 크게 발달하였고, 1월에 발달하지 못했던 냉수성 소용돌이가 발달하기 시작하였다. 위성 표층 수온에서 북위 39~40° 사이에 존재했던 수온전선이 1월과 비슷하게 형성되어있으며, 1월과 비교하여 6~10℃ 정도로 낮아졌다.

> (6월) …난수성, 냉수성 소용돌이가 북위 39~40° 사이에서 강하게 발달하였고, 대마난류의 외해지류가 발달을 보이고 있다. 위성 표층 수온 자료를 보면 동해 해역의 전체적인 수온상승을 볼수있으며, 범위는 12~20℃로 형성된다. 울릉도‧독도 해역의 수온은 18~20℃로 전월 대비 약 4℃ 이상 높다.

> (11월) …11월에는 동한 난류가 크게 발달하였고, 울릉도‧독도 해역에서의 소용돌이 발달이 약해지고 동해 동부 해역에 집중되는 분포가 보여졌다. 위성 표층 수온 자료를 통한 동해 해역의 수온범위는 8~20℃정도로 10월에 비해 수온이 급격히 낮아지고, 북위 40° 기준으로 수온의 변화가 크게 나타났다.

**주요 키워드**: 수온전선, 난수성/냉수성 소용돌이, 동한난류, 대한해협, 대마난류(외해지류), 울릉도‧독도 해역

완성한 12개 코멘트를 `output/intermediate/comments/comments_<연도>.json`에 저장한다. 키는 `"1"`~`"12"`, 값은 **`(N월) `로 시작하는 전체 코멘트 문자열** (문단 앞의 `- ` 같은 접두사는 build_report.py가 템플릿 원문에서 보존하므로 넣지 않음):

```json
{"1": "(1월) 동해에 나타난 소용돌이는 난수성 15개, ...", "2": "(2월) ..."}
```

### 3단계: HWPX 조립

템플릿 `template/template_2025.hwpx`가 있는지 확인. 없으면 사용자에게 "한글(정품) PC에서 2025 보고서를 [다른 이름으로 저장 → HWPX]로 변환해 `template/template_2025.hwpx`로 넣어달라"고 요청하고 여기서 중단.

최초 1회는 템플릿 구조를 검증한다:

```
python code/build_report.py <연도> --inspect
```

- 이미지 등장 순서가 "월 오름차순 × [소용돌이→해류→수온]" 가정과 맞는지 확인 (다르면 code/build_report.py의 IMG_TYPES/매핑 수정)
- `(1월)`~`(12월)` 코멘트 문단, `N월` 표 행이 검출되는지 확인

이후 조립:

```
python code/build_report.py <연도>
```

출력 리포트에서 코멘트 교체 12개월, 표 1 교체 12행, 이미지 36장이 모두 교체되었는지 확인하고, 미달이면 원인을 파악해 수정한다.

### 4단계: 결과 보고

- 최종 파일 경로(`output/report/<연도> 동해 소용돌이 분석보고서.hwpx`)를 SendUserFile로 전달
- 월별 코멘트 요약, 실패/누락된 월, 교체 통계를 보고
- 한컴오피스 뷰어로 열어 서식·그림 확인을 요청
